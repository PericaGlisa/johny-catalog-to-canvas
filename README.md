# JOHNY® · Profesionalni barski mikseri i blenderi

Zvanični prezentacioni sajt brenda **JOHNY** za bariste, kafiće, barove i hotele u distribuciji **EEF Online Professional**.

## O projektu

Prezentacioni sajt visoke preciznosti sa interaktivnim studijom boja, uporednim tehničkim pregledom, direktnim preuzimanjem PDF kataloga i jednim izvorom istine za sve tehničke specifikacije barske opreme.

- **5 modela**: AK/2-2T Timer, AK/2-2T Classic, ECO, AK/2-2T Auto, B/2800 Blender
- **7 boja & završnih obrada**: Crvena, Žuta, Plava, Siva, Krem, Braon, Crna
- **Potpuna responzivnost**: Prilagođeno svim vrstama uređaja, od mobilnih telefona od 320px do 4K ekrana
- **Netlify Ready**: Optimizovano za trenutni deploy na Netlify platformi

## Lokalni razvoj

```sh
# Instalacija zavisnosti
npm install

# Pokretanje lokalnog dev servera
npm run dev

# Pokretanje testova
npm test

# Build za Netlify
npm run build
```

## Netlify Deploy

Projekat sadrži konfigurisan `netlify.toml` za automatsku izgradnju i optimizovane keš zaglavlja.
